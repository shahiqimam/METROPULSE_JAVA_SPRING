# 0001 - Java 21 and Spring Boot

## Context

MetroPulse is intended to demonstrate enterprise Java backend engineering rather than a thin rewrite of a TypeScript service.

## Decision

Use Java 21+ and Spring Boot for the backend and simulator modules.

## Alternatives

- Kotlin with Spring Boot
- NestJS
- Micronaut or Quarkus

## Consequences

The project can demonstrate JVM fundamentals, Spring dependency injection, Spring Security, JPA/Hibernate, transactions, Flyway, Kafka integration, and Testcontainers.
